# HearthDay Today Screen

Status: existing iPhone product, approved redesign boundary

- Primary user: a person checking a small set of self-chosen daily commitments.
- Core task: understand what still matters today and mark one commitment complete.
- Product character: warm, clear, non-judgmental, and private.
- Current navigation and task interactions are approved and out of scope.
- The Today screen contains: greeting, date, three commitments, one completed commitment, and a quiet end-of-day note.
- Representative commitments: “Walk after lunch”, “Call Mum”, and “Read 20 pages”.
- Current project colors: `surfaceBase #F7F2EA`, `contentPrimary #292522`, `actionPrimary #A44E37`.
- Current problem: every section uses the same visual weight, so the remaining commitment does not hold focus.
- User request: compare a calmer editorial hierarchy with a more direct task-led hierarchy.
- No new artwork or brand assets exist.
- Validation status: no proposed direction has been rendered or selected.
