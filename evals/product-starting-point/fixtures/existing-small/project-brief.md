# EchoList Project Brief

Status: current product documentation

- Product: EchoList, a shared household grocery-list app.
- Target platform: iPhone, iOS 17 and later.
- Primary user: a household member adding or checking items during shopping.
- Core task: quickly add, find, and mark an item complete while moving through a store.
- Input: one-handed touch; VoiceOver is supported for the core list path.
- Usage: several short sessions each week, often interrupted.
- Failure cost: low for a missed animation, moderate for checking the wrong item or losing a shared update.
- Existing interaction model: one list per screen, with the list name in the navigation title and items directly below it.
- Confirmed change boundary: improve the visual prominence of the list title only. Do not change navigation, item behavior, sharing, or information architecture.
- Validation status: no new design has been rendered or run.
