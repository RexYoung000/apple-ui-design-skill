# LedgerDesk Current Interface Observation

Status: observation of the shipped macOS app

- The app uses a three-item bottom tab bar labelled Invoices, Payments, and Settings.
- The layout originated in an earlier iPhone prototype and is centered in a fixed-width Mac window.
- Invoice detail opens as a full replacement screen.
- Pointer selection works, but the primary reconciliation path cannot be completed with the keyboard alone.
- There are no roles, shared ownership indicators, or review states in the current interface.

These observations prove what is shipped. They do not establish that the tab model is correct for the next version or that agency workflows are validated.
