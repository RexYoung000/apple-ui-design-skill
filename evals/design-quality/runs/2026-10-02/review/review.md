# OrbitCut iPad / Mac 静态设计审查

结论：四张截图展示了连贯的视觉语言与不同窗口下的布局收放，但不足以认定核心体验验收完成。当前能确认的是指定画面的可见布局；选素材、拖选片段、预览和导出的实际行为均未验证。没有足够证据认定核心任务已经失败，也没有足够证据宣布其通过。

## 可保留的质量

四个画面的色彩、片段身份、选中卡片和主操作语言一致。宽窗口同时呈现素材、编辑与属性，紧凑窗口通过收起区域保留编辑空间；从画面看，适配包含信息组织的变化。选中状态同时有列表强调、圆环边缘与带名字的选中提示。导出入口在四种窗口中均可见。

这些是布局和呈现方面的优点，不证明收起后的操作、选择同步或导出有效。

## 可操作反馈

**Blocking：** 没有能仅凭四张截图确认的 Blocking 问题。缺少行为证据会阻止“体验已验证”的结论，但不能据此推定产品行为失败。

### Important — 当前画面没有提供可审看的视频预览

**观察事实：** 四图的主编辑区中央均为时间、PLAYHEAD 和播放按钮，未显示视频帧。宽布局的选中卡片只有抽象渐变，Mac 状态栏出现 1080 × 1080、30 fps。可见画面中没有明确标注的视频预览入口。

**用户影响：** 当前设计材料无法说明用户怎样核对所选内容、画面裁切、片段连接或循环接缝。播放按钮可发现，不等于结果可审看。

**证据与场景：** 全部四图，选择完成后、预览前的暂停状态。这里只能确认视频预览未在这些状态中呈现，不能断言产品运行时没有预览。

**建议：** 作为核心任务结果要求，补充实际视频预览状态，或让进入画面预览的入口在编辑上下文中可发现，并显示预览时间与选中片段的关系。具体布局仍由产品决定，不要求替换圆环模型。

**验证方法：** 在原生 iPad 和 Mac 中，从选中片段进入预览，播放、暂停、定位片段边界并播放循环接缝；保留正常速度录像，确认用户看到的画面与时间一致。用真实片段核对预览与导出内容一致。

### Important — 圆环范围编辑的可见提示不足，紧凑 iPad 的入口尤其需要核对

**观察事实：** 圆环显示分段颜色、无数字刻度与选中边缘，未呈现明确的起点/终点拖动手柄或拖选提示。三个较宽画面同时提供 Arrange / Trim；紧凑 iPad 只显示 Arrange，Edit 面板提供 Start / Duration / Volume。当前材料没有展示 Trim 激活或拖动中的状态。

**用户影响：** 首次使用者需要自行推断圆环的时间方向、片段边界与“移动片段”和“调整范围”的差异。紧凑 iPad 用户能否发现并完成同样的拖选任务仍不清楚。

**证据与场景：** 四图中的圆环及模式入口，尤其 ipad-compact.png。此项是可发现性风险，不是已证实的手势失效；未展示的菜单、提示或运行反馈仍可能提供所需能力。

**建议：** 作为核心任务结果要求，补充范围编辑的入口与操作反馈，使选中对象、可调整边界及调整后的范围可辨认；为精确调整提供能发现的非拖动等效路径。保留圆环交互，先验证其学习与操作成本，不因其非标准而改成线性时间轴。

**验证方法：** 不先讲解手势，让用户在两种 iPad 窗口和两种 Mac 窗口中选择指定片段并调整起止范围；记录首次找到入口、拖动、撤销及重做的结果。分别使用触控和指针，核对最短片段、跨循环边界、拖动中取消、快速反向操作与输入替代路径。

### Optimization — 环境说明占据了产品主内容的注意力

**观察事实：** 四图在标题下均有显著的窗口/平台/输入说明，例如 “IPAD · COMPACT WINDOW · TOUCH / PENCIL / POINTER” 和 “MAC · MINIMUM 900 × 640 · POINTER / KEYBOARD”。

**用户影响：** 这些说明对评审有用，但在实际剪辑任务中与内容、选中范围和下一步操作竞争注意力。它们也不能证明列出的输入方式已经可用。

**证据与场景：** 全部四图的 COMPOSITION 标题区。

**建议：** 可选优化：若这些是评审标记，将其放在画面外的图注或验证记录中；若是拟上线界面，应核对它们是否帮助用户作出任务决定，再决定是否保留。

**验证方法：** 查看最终面向用户的画面与评审图注，确认产品界面优先传达当前项目、选择和操作状态；输入支持另由运行记录证明。

## 认定体验验收完成仍缺什么

以下是与四个核心任务直接相关的证据缺口，不是已经确认的缺陷：

| 缺口 | 最小补证与预期结果 |
| --- | --- |
| 真实内容与选素材 | 使用可辨识的真实素材，展示导入、选择、替换/移除、空项目、慢导入与失败恢复；素材身份、当前选择与编辑对象对应清楚 |
| 圆环操作与精度 | 展示选择、拖选/修剪、数值调整、取消、撤销/重做、最短片段及循环边界；结果反映最后一次输入，操作中与结束后的反馈一致 |
| 预览 | 展示真实画面、播放/暂停、定位、片段连接和循环接缝；游标、选中范围及画面同步，连续操作无需等待无关表现 |
| 导出 | 展示范围/格式/目标位置、进行中、取消、失败重试和真实完成；打开实际导出文件核对画面、时长、音画同步及保存位置，不能以成功标签代替文件证据 |
| 窗口适配 | 原生环境中连续缩放与切换面板；核对素材选择、编辑范围、播放位置、未完成输入和焦点保留，必要操作仍可到达 |
| 输入与命令 | iPad：触控、键盘、指针；若 Pencil 是实际支持承诺，再验证 Pencil。Mac：指针、键盘独立完成、可见焦点、相关菜单/快捷键、撤销与焦点恢复；图片上的输入徽标和快捷键提示不能代替操作记录 |
| 无障碍 | 检查自定义圆环的名称、角色、范围值、状态和操作；提供范围调整的非拖动路径。在所声明的平台完成具名的 VoiceOver 核心任务运行；iPad 键盘路径同时核对 Full Keyboard Access。语义检查和自动化不能写成辅助技术运行通过 |
| 内容与显示扩展 | 用长文件名、中文/混合文字和任务相关文字放大验证列表、数值、按钮与面板重排；对实际表面测量对比度并核对 Increase Contrast。只按产品实际支持范围补证语言与显示模式 |
| 动效与恢复 | 有实质动效时提供正常速度与 Reduce Motion 运行记录，核对中断、重复和反向输入；补充导入/编辑/导出中断后的进度和项目恢复证据 |

每条运行记录应注明构建版本、系统、设备/真机或模拟器、窗口大小、输入、设置、路径、观察结果及证据位置。不同平台、输入和辅助技术不能相互代替。

## 最短验收路径与完成阶段

1. 在真实 iPad 与 Mac 运行中导入一组真实素材，选择指定内容，拖选范围并用替代输入完成同一调整；撤销后恢复原范围，再重做。
2. 在紧凑与宽窗口间切换，打开/收起素材和属性区域，确认选择、范围、播放位置及焦点保留。
3. 预览调整后的内容，定位片段边界并看完整循环；画面、声音、时间和范围保持一致。
4. 执行一次取消、一次可控导出失败与重试，再完成导出；打开文件核对实际内容、时长和保存位置。
5. 用键盘独立完成核心链路，再完成各声明平台的具名辅助技术路径；核对任务相关显示设置与文字扩展。若有实质动效，验证 Reduce Motion。
6. 完成代理验证后，由 Rex 在实际结果上确认视觉、操作和最终体验；未验证的平台、输入或情境仍须列明。

当前已完成的是这次静态 UI Review，不把它映射成产品的更晚完成阶段。四图不足以宣布 **design complete**、**prototype complete**、**code complete**、**experience verified** 或 **user accepted**；**direction aligned** 也需要已有的明确方向确认，目前材料未提供。完成所需的原生任务与风险场景验证后，才有依据认定范围内 **experience verified**；Rex 检查实际结果并确认后才是 **user accepted**。
