# OrbitCut：iPad → Mac 设计适配

保留径向时间线、安静深色和暖色主操作，把同一套选素材 → 选片段 → 预览 → 导出任务，翻译成可缩放窗口中的键盘与指针工作台。主合同为 **Platform Adaptation**；本稿不扩展品牌、剪辑功能或跨设备服务。

## 来源与范围

- 用户确认：已有 iPad 设计；Mac 完成选素材、拖选片段、预览、导出；保留安静深色 DNA；只做设计适配。
- 源设计事实：`prototype/index.html`、`styles.css`、`app.js` 中有六段素材、径向时间线、选中态、起点/时长/终点、播放与导出入口。源 README 明确其为静态布局稿；不能据此断言拖拽、保存、导出或 Mac 行为已实现。
- 本次设计推断：拖选片段落在已有 Trim 的时间范围上。保留 Ocean Foam 的源范围 8.4–13.0 秒，用两端边界调整选中范围；不新增切分、磁吸规则、轨道、批量操作、云同步或多窗口。
- 目标窗口提案：紧凑 900 × 640、常用 1180 × 760、宽 1440 × 900。浏览器实际可视区可小于提案尺寸；这些是继承源设计并适配后的审阅值，未获最终视觉验收。最低 macOS 版本和生产工程并未提供，本稿不指定 API 或系统材料版本。

## 「拖起来跟手，松开回弹」保留的是控制感

跟手的目的，是让用户持续看见“我正在调整哪个对象、此刻会取哪段时间”。拖动期间端点与指针同步，圆环、详情和时间读数使用同一个暂存范围；不让先前的动画拖着新输入走。

回弹的目的，是说明暂存形态已回到稳定状态：拖动中端点/选中弧略抬起，释放后回到环上，时间范围已经提交。回弹只改变显示的抬起程度，不偷偷把时间点移走，也不让用户等待才能再次操作。它延续轻微弹性和安静的 DNA；不是每次播放、选择或窗口变化都应弹一下。

| 状态 / 事件 | 预期结果 | 等效键盘结果 |
| --- | --- | --- |
| 选中素材 | 显示该素材的完整源范围 | 列表上下键选择，Enter 确认；同一名称和范围 |
| 抓住入点 / 出点 | 保留操作前范围，显示端点正在调整 | Tab 到“入点”/“出点”；开始编辑时保留原值 |
| 持续拖动 | 限于当前素材范围；实时读数，不只变颜色 | 箭头每次 0.1 秒；Shift＋箭头 1 秒；直接输入秒数 |
| 释放 / Enter | 提交最后合法范围；外观轻轻落回稳定圆环 | Enter 提交同一值；保留焦点，读出更新后的起止与时长 |
| 反向或快速再拖 | 最新输入接管当前形态，不排队播放回弹 | 连续按键立即累积，不需要等动画 |
| Esc / 失去拖动捕获 / 窗口失焦 | 回到操作前范围；取消不算一次成功编辑 | Esc 恢复操作前字段；焦点留在可继续编辑处 |
| 越界或起点 ≥ 终点 | 保留最后合法范围，并说明当前素材边界 | 字段提示错误，不自动提交不合法输入；修正后继续 |
| 撤销 / 重做 | 一次完成的范围调整是一项可恢复操作 | ⌘Z / ⇧⌘Z 恢复范围与选择；拟用快捷键需原生验证 |

时间调整步长是本次设计提案，沿用源设计中的 0.1 秒 / 1 秒提示，不代表生产精度或逐帧规则已确定。源稿没有可测的弹簧参数；本稿也不从浏览器时长推断原生手感。

## 同等任务结果与焦点顺序

Mac 纯键盘路径：到素材列表 → 上下键选素材 → Tab 到详情或时间字段 → 调整入点/出点 → Enter 提交 → Space 预览 → 顶栏 Export Loop → 取消或确认保存。建议菜单映射 File > Import、File > Export Loop、Edit > Undo/Redo、View > Inspector、Playback > Play/Pause；这都是现有任务的入口，不新增任务。

顺序：顶栏已有命令 → 素材列表 → 圆环说明/两个端点 → 范围字段或“Inspect” → 预览 → 导出对话内容。圆环的装饰 tick 不进入焦点树。窄窗详情关闭时还给 Inspect；导出取消时还给 Export Loop；不能把焦点留在隐藏面板。

本次 HTML 提供模式切换、素材选择、端点拖动、时间字段、键盘增减、取消、撤销、简化预览和导出边界说明，都是用于审阅设计的浏览器演示。播放只是示意进度；导出不生成视频、不模拟系统保存成功。

## 用户验收路径

1. 浏览器打开 `index.html`，切换“紧凑 / 宽”，检查两种布局都把圆环编辑放在中心；再缩放窗口，确认 Export Loop 与播放可见。
2. 选择 Ocean Foam，检查名称、选中弧、范围 8.4–13.0 秒一致。拖动橙色入点，释放；按 Esc 取消一次，再撤销一次。
3. 紧凑模式点 Inspect，通过入点/出点字段和箭头得到相同范围；关闭详情后焦点应回 Inspect。
4. 播放/暂停观察示意播放头；点 Export Loop，看到明确的设计演示边界，取消后仍在同一范围。
5. 在真实 Mac 原型中按上述任务矩阵验证原生输入、辅助技术、导出与减少动态效果，再由 Rex 验收最终视觉和手感。本次浏览器检查不能跳过此步骤。
